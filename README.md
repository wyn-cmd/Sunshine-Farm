# Sunshine Farm

A terminal-based farming simulation game written in Python. You take out a loan to buy a small farm in the town of Prixia and have 20 days to pay off a $50 debt by planting, harvesting, and selling crops.

## Features

- **Crop Management:** Buy seeds with varying prices, growth times, and return values (Lettuce, Potato, and Cauliflower).
- **Farm Grid:** Manage a 5x5 grid layout featuring your house and farm plots.
- **Dynamic Pricing:** Crop prices fluctuate daily as you manage your daily energy and funds.
- **Leaderboard:** Track your best runs and high scores in a local leaderboard.

## Requirements

- Python 3+

## Usage

Run the game from the terminal:

```bash
python3 main.py
```
